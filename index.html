CADDY CONTAINER

colors-redirect

A single-purpose container that permanently redirects apex and legacy traffic to www.getcolors.ai while preserving each request path and query string.

  • /up returns a plain-text health response.
  • Every other route returns a permanent redirect.
  • TLS terminates at the host proxy; the container serves plain HTTP.
